# Campus Ledger — Student Academic Management System

React + React Router + JavaScript + CSS + localStorage college project.

## Run
```bash
npm install
npm run dev
```

## Pages
1. Overview
2. Learner Directory
3. Marks & Gradebook
4. Attendance Tracker
5. Performance Insights

## Storage
The application stores learners, marks, and attendance in browser localStorage under:
- `campus-ledger-learners`
- `campus-ledger-marks`
- `campus-ledger-attendance`

No backend or database is required.
