# Sridhar Cloud-Themed React Portfolio

A six-page student portfolio built with React and React Router using BrowserRouter.

## Pages
- Home
- About
- Introduction
- Projects
- Skills
- Contact

## Run locally

```bash
npm install
npm run dev
```

Then open the local Vite URL shown in the terminal.

## Notes
- The profile photo is already included at `src/assets/profile.jpg`.
- Replace the placeholder GitHub, LinkedIn and email links in `src/pages/Contact.jsx` with your real links.
- Project descriptions can be edited in `src/pages/Projects.jsx`.
